**项目名称：** Siftory  
**名称来源：** Sift（筛选、提炼）+ Story（故事）  
**英文发音：** /ˈsɪf.tə.ri/  
**中文音译：** 思拓瑞（暂定）

**品牌 Slogan：** *From Information to Story.*（从信息到故事）

---

## 一、产品介绍（Product Overview）

**Siftory 是一款 AI 驱动的自主研究与视频创作 Agent。**

它能够围绕指定主题或资讯领域，自主完成信息发现、资料收集、内容研究、知识提炼、文案创作、视觉素材生成、语音合成及视频制作，将分散的原始信息转化为结构完整、具有叙事价值的视频内容。

Siftory 不仅仅是一个 AI 视频生成工具，更是一个集 **信息研究、内容理解、创意表达和多模态内容生产** 于一体的智能创作系统。

用户只需定义研究方向、内容主题或信息来源，Siftory 即可自动执行从信息获取到视频生成的完整工作流程。

### 产品愿景（Vision）

> Transform Information into Stories Worth Watching.
>
> 将信息转化为值得观看的故事。

让有价值的信息不再局限于文字，而是通过 AI 自动转化为直观、生动、易于理解和传播的视频内容。

### 产品使命（Mission）

降低从信息获取到内容创作的门槛，让 AI 成为能够自主研究、理解、表达和创作的智能内容生产者。

## 二、核心价值（Core Values）

Siftory 的核心竞争力并非单纯的视频生成能力，而是 **将复杂、分散的信息转化为有价值、有逻辑、有表现力的视频故事的能力。**

### 1. 信息发现（Discover）

从海量信息中发现值得关注的内容。

支持通过搜索引擎、RSS、指定 URL 资源池等多种渠道获取信息。

核心价值：
- 多来源信息聚合
- 自动化信息发现
- 主题相关性分析
- 有价值信息筛选

### 2. 知识提炼（Synthesize）

从原始信息中提取真正有价值的知识。

通过 AI 对多来源资料进行分析、总结、去重、归纳和组织，形成具有逻辑结构的内容。

核心价值：
- 信息理解与分析
- 多来源内容整合
- 核心观点提取
- 知识结构化
- 事实与来源追溯

### 3. 故事构建（Narrate）

将知识转化为具有吸引力的叙事内容。

Siftory 不只是对资料进行摘要，而是根据视频目标、受众及内容风格，将研究结果组织成适合视频表达的故事。

核心价值：
- 自动化视频文案创作
- 叙事结构设计
- 分镜脚本规划
- 内容节奏控制
- 不同表达风格适配

### 4. 视觉呈现（Visualize）

将抽象的信息转化为直观的视觉表达。

通过 AI 图片生成、语音合成及视频制作技术，将文案转换为完整的视听内容。

核心价值：
- AI 视觉素材生成
- AI 语音与旁白合成
- 画面与音频同步
- 自动化视频剪辑与合成
- 多种视频规格输出

### 5. 自主执行（Automate）

让内容生产从人工操作转变为 Agent 自主执行。

通过自动化工作流，将研究、创作与制作环节连接起来，减少人工重复劳动。

核心价值：
- 端到端自动化
- 可配置的任务流程
- 定时执行与持续研究
- 模块化能力扩展
- 支持人工审核与干预

## 三、设计理念（Design Philosophy）

### 1. Research First — 研究优先

**内容质量首先取决于信息质量，而不是生成模型的表现能力。**

Siftory 以研究为起点，而非直接从提示词生成视频。

在内容创作之前，优先完成信息收集、来源验证、内容分析与知识提炼。

这一理念使 Siftory 区别于传统的 Text-to-Video 工具。

### 2. Story Driven — 叙事驱动

**信息是原材料，故事才是最终产品。**

优秀的视频不仅需要准确的信息，还需要清晰的叙事结构。

Siftory 将内容组织与故事表达作为核心能力，确保最终视频不仅能够传递信息，还能够让观众理解信息。

### 3. Agent Native — Agent 原生

**不是为传统视频编辑器增加 AI 功能，而是让 AI Agent 自主完成视频创作。**

Siftory 采用 Agent 驱动的设计思想。

Agent 能够根据目标自主规划任务、调用工具、分析结果，并协调不同的内容生产能力。

用户负责定义目标，Agent 负责完成执行。

### 4. Modular & Extensible — 模块化与可扩展

**每项能力独立构建，通过标准化接口组成完整工作流。**

信息获取、内容研究、文案生成、图片生成、语音合成、视频制作等能力应尽可能解耦。

不同模块可以自由替换底层服务或模型。

例如：
- 搜索引擎可以替换
- LLM 可以替换
- 图片生成模型可以替换
- TTS 服务可以替换
- 视频渲染引擎可以替换

这种架构有利于持续迭代、技术升级和社区扩展。

### 5. Human in Control — 人类掌控

**自主执行不意味着失去控制。**

Siftory 应支持在关键环节进行人工审核与修改。

例如：
- 审核研究结果
- 修改视频文案
- 调整分镜结构
- 重新生成视觉素材
- 选择语音与表现风格
- 确认最终视频

系统既可以全自动运行，也可以采用人机协作模式。

## 四、核心概念（Core Concepts）

Siftory 的核心工作流程可以抽象为五个阶段：

**Discover → Synthesize → Narrate → Generate → Produce**

| 阶段 | 核心概念 | 主要职责 | 主要产物 |
|---|---|---|---|
| 1 | Discover | 信息发现与采集 | 原始信息集合 |
| 2 | Synthesize | 信息分析与知识提炼 | 结构化研究报告 |
| 3 | Narrate | 内容策划与叙事构建 | 视频文案与分镜脚本 |
| 4 | Generate | 多模态内容生成 | 图片、音频等素材 |
| 5 | Produce | 视频编排与合成 | 最终视频文件 |

## 五、核心功能（Core Features）

### 1. 智能信息采集

支持多种信息来源：

- 搜索引擎
- RSS Feed
- 指定 URL 资源池
- 网站文章
- 其他可扩展数据源

根据研究主题自动收集相关资料，构建原始信息集合。

### 2. AI 研究与内容提炼

对采集的信息进行智能处理：

- 内容清洗与去重
- 信息分类
- 相关性评估
- 关键信息提取
- 多来源交叉验证
- 内容总结与归纳

生成结构化研究结果，为后续创作提供可靠的信息基础。

### 3. 智能文案创作

根据研究结果自动生成视频文案。

支持不同内容形式，例如：

- 新闻资讯
- 科技解读
- 财经分析
- 知识科普
- 专题研究

根据目标视频长度、受众及表达风格调整叙事结构。

### 4. AI 视觉素材生成

根据视频文案及分镜描述生成视觉素材。

主要包括：

- 场景图片
- 概念插画
- 内容配图
- 视频封面

支持统一视觉风格，保持不同场景之间的视觉一致性。

### 5. AI 音频生成

通过 TTS 技术将视频文案转换为语音。

主要能力：

- 文本转语音
- 不同声音风格
- 语速与语调控制
- 分段旁白生成

后续可扩展背景音乐与音效生成。

### 6. 自动化视频制作

将视觉素材、音频与分镜脚本进行自动化编排。

主要能力：

- 画面时长计算
- 图片动态效果
- 场景切换
- 音画同步
- 字幕生成
- 视频编码与导出

最终输出可直接观看和发布的视频文件。

## 六、产品定位与差异化

Siftory 不应被定义为普通的 AI Video Generator。

更准确的定位是：

**AI Research-to-Video Agent**

即：从研究到视频的智能创作 Agent。

| 产品类型 | 主要能力 | 与 Siftory 的区别 |
|---|---|---|
| AI 搜索工具 | 搜索与总结信息 | 缺少完整的视频创作能力 |
| AI 写作工具 | 生成文案 | 缺少自主研究和多模态制作 |
| AI 图片生成工具 | 生成视觉素材 | 不负责研究与叙事 |
| AI 视频生成工具 | 根据提示词生成视频 | 不一定具备信息研究与事实验证能力 |
| **Siftory** | **研究、提炼、叙事、生成、制作** | **以信息研究为基础的端到端视频创作** |

Siftory 的差异化竞争力在于：

**Research Intelligence + Storytelling + Multimodal Production + Agent Automation**

## 八、产品演进方向

### Phase 1 — MVP：端到端视频生成

首先验证核心工作流程。

目标是实现：

**输入主题 → 自动研究 → 生成文案 → 生成图片 → 生成语音 → 合成视频**

重点关注完整性、稳定性及视频内容质量。

### Phase 2 — 智能化与可控性

增强 Agent 的研究与创作能力。

包括：

- 自主研究规划
- 多来源事实验证
- 可编辑的视频分镜
- 内容审核与修改
- 多种视频风格
- 任务失败恢复

### Phase 3 — 持续内容生产

从单次视频生成发展为持续运行的内容生产 Agent。

包括：

- 主题订阅
- RSS 持续监控
- 定时研究任务
- 自动发现热点
- 自动生成系列视频
- 多平台发布

最终形成一个能够持续发现信息、研究内容并生产视频的智能系统。

## 十、项目核心原则

Siftory 的长期发展可以围绕五项原则展开：

1. **Research First** — 以高质量研究为内容创作的基础。
2. **Story Driven** — 以叙事组织信息，而非简单拼接内容。
3. **Agent Native** — 让 Agent 自主规划并执行完整创作任务。
4. **Modular by Design** — 通过模块化架构支持不同模型、工具和服务。
5. **Human in Control** — 保持自动化能力与人工控制之间的平衡。

### 最终产品定义

**Siftory — From Information to Story.**

Siftory 的本质不是一个自动化视频剪辑工具，而是一个**以信息研究为起点、以叙事表达为核心、以视频为最终载体的自主内容创作 Agent**。

它的核心理念可以概括为：

**发现信息 → 理解信息 → 提炼价值 → 构建故事 → 视觉表达。**

这也将成为 Siftory 后续产品设计、Agent 架构和功能演进的统一指导思想。
